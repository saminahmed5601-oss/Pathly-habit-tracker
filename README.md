# 🌱 Pathly — Cozy Daily Progress & Milestone Tracker

> **A clean, cute, dopamine-rich, and cheat-proof daily life progress tracker built with Next.js, React, TypeScript, and Tailwind CSS.**

---

## ✨ Features

- 🎯 **Retroactive Starting Offset**: Start tracking any long-term goal or course (e.g. *12-Milestone Web Dev Bootcamp*) from where you left off (e.g. Milestone 3/4) without having to restart from zero.
- 🛡️ **Anti-Cheat Pacing Guard ("Proof of Work")**: Protects your genuine dopamine by enforcing a reflection note (*"What did you build or learn?"*) and pacing cooldowns to prevent accidental/fake multi-clicks.
- 🌅 **Sunrise Kickoff Ritual**: Rule of 3 daily focus intention setter (1 Primary Mission + 2 Supporting Habits + Planned focus hours).
- ⏱️ **Focus Room & Pomodoro**: Built-in 15m, 25m, 45m, and 60m deep work timers linked directly to your active milestones.
- 👥 **Friend Pod & Social Accountability**: Live accountability squad where buddies can track each other's progress and send one-click emoji boosts (🔥 *Fire*, ☕ *Coffee*, 🌟 *Superstar*, 💪 *Crushing It*).
- 🌸 **Evolving Mascot Seedling**: Watch your daily seedling grow from 🌰 *Seed* → 🌱 *Sprout* → 🌿 *Sapling* → 🌺 *Bud* → 🌸 *Radiant Bloom* as you complete genuine work.
- 📸 **Shareable Progress Cards**: Export beautiful aesthetic report cards to share on WhatsApp, Discord, or Twitter.
- 🎨 **Cozy Aesthetic Themes**: Pastel Cozy, Cocoa Dark Mode, Matcha Green, and Lavender Dream.
- 🔊 **Tactile Sound Effects**: Synthesized Web Audio API chimes and celebratory fanfare.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio**: Web Audio API Synthesizer
- **Animations**: Canvas Confetti & CSS Micro-Interactions
- **Storage**: LocalStorage with JSON Export/Import Support

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/mahunn/pathly-habit-tracker.git
cd pathly-habit-tracker
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📖 The Pathly Philosophy

1. **The Rule of 3**: Limit your morning intentions to 1 big win and 2 supporting habits.
2. **Minimum Viable Day**: Protect your streak on low-energy days with 15 minutes of light focus.
3. **Compound Consistency**: 1% improvement every day leads to exponential results over time.
